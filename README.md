# MedBooking / RehabConnect — Руководство по публикации и развертыванию

Международная веб-платформа для поиска и бронирования многопрофильных больниц, клиник и реабилитационных центров в Душанбе, Ташкенте и Стамбуле.

---

## 🚀 Варианты публикации

### Вариант 1. Автономный статичный сайт (Pure HTML, CSS, Vanilla JS)
В папке `standalone/` (и `public/standalone.html`) подготовлен полностью автономный код без Node.js и зависимостей:
- `standalone/index.html` — разметка, семантика, модальные окна и структура.
- `standalone/styles.css` — стили, кастомные маркеры и стили Leaflet.
- `standalone/app.js` — интерактивная логика, база клиник, фильтрация по ценам и городам, геолокация, расчет расстояний, переключение темной темы и бронирование.

**Как опубликовать:**
1. Загрузите файлы из папки `standalone/` в любой статический хостинг: **GitHub Pages**, **Vercel**, **Netlify**, **Cloudflare Pages**, или на обычный сервер Apache/Nginx.
2. Либо просто откройте `standalone/index.html` двойным кликом в любом браузере.

---

### Вариант 2. Production-сборка React SPA (dist/)
Проект компилируется в оптимизированный набор HTML, CSS и JS с минификацией:
```bash
npm run build
```
Результат сборки находится в директории `dist/`:
- `dist/index.html`
- `dist/assets/*.css`
- `dist/assets/*.js`

**Как опубликовать `dist/`:**
- **Vercel**: `vercel deploy --prod`
- **Netlify**: `netlify deploy --prod --dir=dist`
- **Nginx**: скопировать содержимое папки `dist/` в `/var/www/html/`

## 🗄 База данных (PostgreSQL + Prisma)

Схема базы данных находится в `prisma/schema.prisma`:
- `Clinic` — больницы, рехабы, клиники (название, координаты, рейтинг, категория, контакты).
- `Doctor` — врачи, специальности, стаж.
- `Service` — программы лечения, сроки и цены.
- `Booking` — заявки пациентов с привязкой к клинике, врачу и услуге.

Для генерации клиента и применения миграций:
```bash
npx prisma generate
npx prisma db push
```

## ⚙️ Ключевой функционал
1. **Поиск и фильтры**: выбор города (Душанбе, Ташкент, Стамбул), категорий (Больница, Рехаб, Наркология, Психология, Ортопедия), фильтр предельной цены и сортировка (дешевле/дороже/рейтинг).
2. **Геолокация**: расчет дистанции в км от текущего местоположения до каждого учреждения.
3. **Карта OpenStreetMap (Leaflet)**: автоцентрирование, интерактивные метки с карточками и адаптация под темную тему (CartoDB Dark Matter).
4. **Темная тема (Dark Mode)**: переключение по кнопке с запоминанием в `localStorage`.
5. **Онлайн-бронирование**: модальное окно с выбором врача, программы и генерацией кода подтверждения.
